# L200 Diagnóstico v0.3

App de diagnóstico para la pantalla Android (TS18, Android 12) de la L200.
Revisa qué cámaras, dispositivos USB, apps y funciones expone el sistema,
y permite probar cada cámara en vivo.

El APK se compila solo con GitHub Actions al subir cambios a `main`.
Queda en la pestaña **Releases** (archivo `L200Diag.apk`).
